# Regras do Projeto CALCULADORA-UTI-AVC

## Teste em Localhost
- Sempre que o usuário solicitar **"localhost"**, inicie imediatamente o servidor de desenvolvimento local na porta 3000 (`npm run dev` em background / daemon) e forneça o link `http://localhost:3000/` para que ele possa testar as alterações antes de fazer o deploy no Easypanel.
